# Support

This is a personal, unofficial project. It is not a Splunk product and is not
covered by any Splunk support contract. It uses Splunkbase's undocumented JSON
API, which can change without notice; a weekly workflow checks for drift.

Questions and bugs: open a GitHub issue. For supported Splunk products, see
[Working with Splunk Support](https://www.splunk.com/en_us/resources/working-with-splunk-support.html).
