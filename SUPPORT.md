# Support

This is a personal project, developed and maintained on its own time.

- **Not for production use.** Use it for labs, demos and development
  environments, and review the output before relying on it anywhere else.
- **Not endorsed or supported by Cisco or Splunk.** It is not a Splunk or
  Cisco product, and no Cisco or Splunk support contract, including Splunk
  Support cases, covers it.
- **Unofficial API.** It uses Splunkbase's undocumented JSON API, which can
  change without notice; a weekly workflow checks for drift.
- **No warranty.** It is provided "as is" under the [Apache-2.0](LICENSE)
  license.

Questions and bugs: open a GitHub issue; responses are best effort. For
supported Splunk products, see
[Working with Splunk Support](https://www.splunk.com/en_us/resources/working-with-splunk-support.html).
